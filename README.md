# EARTH//NEXT

**NASA Space Apps 2026 — challenge: *Be an Earth System Trend Detective*.**

Case-file investigation tool for Earth-system trends. Pick a NASA variable,
pick two regions, see whether each is changing — with every assumption visible
and every number traceable to the exact file, filter, and library version that
produced it.

Status: **running on real NASA data.** Nile Delta + Sahara Interior (Egypt),
NDVI from MODIS/Terra MOD13A3.061, monthly, 2000-02 → 2026-09, via NASA
AppEEARS. Full method and sources in `docs/`.

---

## Quick start (fresh clone)

Prerequisites on your machine:
- **Node.js 20+** and **pnpm** (install pnpm once with `npm i -g pnpm`)
- **Python 3.11 or 3.12** on PATH as `python`
- Git Bash **or** PowerShell with `RemoteSigned` execution policy
  (`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`),
  **or** just call scripts as `npm.cmd` instead of `npm`

```bash
# 1. install everything (one-shot: Python venv + Python deps + web deps)
npm run setup

# 2. verify
npm test                # 44 pytest + 26 vitest, should print "All tests PASS."

# 3. regenerate the JSONs the UI reads (idempotent)
npm run process

# 4. dev server
npm run dev             # http://localhost:3000
```

> The dev server auto-reloads on file save. Any time you edit `science/` code
> or `web/public/data/*.json`, the UI picks it up.

## npm scripts

| Script | What it does |
|---|---|
| `npm run setup` | Create `science/.venv` + install Python deps + `pnpm install` in `web/` |
| `npm test` | Run both pytest and vitest, in that order |
| `npm run test:py` | Python tests only |
| `npm run test:web` | Web tests only |
| `npm run process` | Ingest AppEEARS NetCDFs → run stats engine → write `web/public/data/*.json` |
| `npm run dev` | Start Next.js dev server on `http://localhost:3000` |
| `npm run build` | Next.js static export to `web/out/` (ready for Vercel / any static host) |
| `npm run lint:py` | Ruff |

## Data pipeline

1. **Acquire NASA data** via NASA AppEEARS Area Sample. Submit a request per
   region with the polygon definitions in
   `science/data/raw/appeears/{nile_delta,sahara_interior}.geojson`, product
   `MOD13A3.061`, layers `_1_km_monthly_NDVI` + `_1_km_monthly_pixel_reliability`,
   dates 2000-02-18 → 2026-09-30, format NetCDF-4. Drop the resulting
   `MOD13A3.061_1km_aid*.nc` under the matching region folder.
2. **Ingest + validate + export** by running `npm run process`. The pipeline
   auto-detects whether real NASA files are present and flips the JSON's
   `source.kind` between `"DEMO"` and `"NASA"` accordingly. The UI shows a
   banner when it's on DEMO data.
3. **View** in the browser via `npm run dev` or the static build.

Fresh contributors with no NASA data on disk: `python scripts/make_demo_data.py`
generates a seeded synthetic dataset so you can run the full pipeline locally
before (or without) submitting an AppEEARS request. The result is clearly
labeled DEMO.

## Environment

`.env` holds Earthdata credentials used by the Stage-2 single-file downloader
(`scripts/fetch_one_mod13c2.py`) and by any future AppEEARS automation. Copy
`.env.example` and fill in your own credentials — **never commit `.env`**;
`.gitignore` covers it.

## Hard rules

Every contribution follows `AGENTS.md`:

- Never invent data, findings, citations, or units. Unknown → `null` with a note.
- Every number in the UI comes from an exported JSON produced by a tested script.
  No hand-typed numbers in components.
- Statistical honesty: Theil-Sen + Mann-Kendall with autocorrelation handling,
  cos(lat) area weighting, Benjamini-Hochberg FDR for multi-cell tests,
  `p < 0.001` never `p = 0.000`.
- UI language: "No statistically detectable trend at α = 0.05 with this data."
  Never "no change", "causes", "proves".
- Scenarios always labeled "Illustrative scenario — not a validated causal forecast".
- Moon/Mars never run through the Earth trend engine. Textured context cards only.
- No NASA logos/insignia. No secrets in the browser. No network call needed to
  render the demo (offline-first, cached JSON).
- SI (Super Intelligence / AI) use disclosed per the challenge FAQ — see
  `docs/ai-use-disclosure.md`.
